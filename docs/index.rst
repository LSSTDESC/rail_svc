pz-rail-svc
===========

A service for managing photometric redshift (photo-z) estimation workflows for
the LSST DESC. Provides a database-backed catalog of algorithms, models,
datasets, estimators, and photo-z estimates, accessible via local Python API,
REST API, or CLI.
